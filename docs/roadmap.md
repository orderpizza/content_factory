# Roadmap

## Milestone 1 — Deterministic Detection

Status: active and continuously tuned.

- Maintain deterministic scoring, clustering, source health, and SQLite
  observability.
- Expand sources only behind the common observation contract.

## Milestone 2 — o2 English End-to-End Target

Status: current focus.

- Use Gemini determination to create an explicit o2 `ContentJob`.
- Generate and validate the fixed idiom carousel.
- Render and persist the complete PNG asset set.
- Finalize the system-level Posting Agent design and prove one o2 Instagram
  publication.

## Milestone 3 — Shared Posting Capability

Status: after the o2 target.

- Define platform adapter, public-media, retry, cadence, and audit contracts.
- Keep scheduling and delivery outside pipelines.
- Add dashboard observability without dashboard controls.

## Milestone 4 — Additional Pipelines

Status: deferred.

- Add new o2 formats through their own contracts and visual profiles.
- Add Bluesky and other platform-specific pipelines through the same persisted
  handoff chain.
- Do not introduce generic orchestration before repeated concrete needs prove it.
